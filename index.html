How It Works

  • 🔦 Device flashlight blinks encoded binary pulses
  • 🌐 Each character is transmitted as 8-bit optical pulses
  • 📊 Live progress bar tracks transmission completion
  • ⚠️ Torch errors are caught safely — the app never crashes

This system uses your device camera flashlight as a Li-Fi optical transmitter. A photodiode/LDR-based receiver on the other end can decode the light pulses back into the original zone code or custom message.
